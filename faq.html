FAQ

คำถามที่พบบ่อย (FREQUENTLY ASKED QUESTIONS) รวมคำตอบสำหรับข้อสงสัยเกี่ยวกับสินค้าและบริการของ AZRAEL

AZRAEL จำหน่ายสินค้าและบริการอะไรบ้าง?

AZRAEL ให้บริการจำหน่าย SAMP Scripts, และระบบเสริมต่าง ๆ สำหรับเซิร์ฟเวอร์ SAMP รวมถึงบริการพัฒนาระบบตามความต้องการของลูกค้า

หลังจากชำระเงินแล้วจะได้รับสินค้าอย่างไร?

หลังจากชำระเงินสำเร็จและระบบตรวจสอบรายการเรียบร้อยแล้ว คุณจะได้รับไฟล์สินค้าหรือสิทธิ์ดาวน์โหลดผ่านช่องทางที่ร้านกำหนด หากไม่ได้รับสินค้าสามารถติดต่อทีมงานเพื่อตรวจสอบได้

สามารถแก้ไข Source Code ของสินค้าได้หรือไม่?

ผู้ซื้อสามารถปรับแต่งสินค้าตามขอบเขตสิทธิ์การใช้งานที่ร้านกำหนด แต่ไม่อนุญาตให้นำ Source Code ไปเผยแพร่ แจกจ่าย หรือจำหน่ายต่อโดยไม่ได้รับอนุญาตจากเจ้าของผลงาน

หากติดตั้งสินค้าไม่เป็น สามารถขอความช่วยเหลือได้ไหม?

ได้ครับ หากพบปัญหาในการติดตั้งหรือใช้งาน สามารถติดต่อทีมงานผ่าน Discord ของ AZRAEL เพื่อขอคำแนะนำและความช่วยเหลือทางเทคนิค

สินค้าที่ซื้อไปแล้วจะได้รับการอัปเดตหรือไม่?

การอัปเดตและแก้ไขข้อผิดพลาดจะขึ้นอยู่กับเงื่อนไขของสินค้าแต่ละรายการ กรุณาตรวจสอบรายละเอียดสินค้า หรือติดต่อทีมงานเพื่อสอบถามเพิ่มเติม

สามารถขอคืนเงินหลังจากซื้อสินค้าได้หรือไม่?

เนื่องจากสินค้าของเราเป็นสินค้าดิจิทัล การคืนเงินจะเป็นไปตามนโยบายการคืนเงินของร้านค้า โดยกรณีสินค้ามีปัญหาจากความผิดพลาดของร้าน สามารถติดต่อทีมงานเพื่อให้ตรวจสอบได้

สามารถสั่งพัฒนาระบบเฉพาะสำหรับเซิร์ฟเวอร์ได้หรือไม่?

ได้ครับ AZRAEL มีบริการพัฒนาระบบตามความต้องการของลูกค้า สามารถติดต่อทีมงานเพื่อแจ้งรายละเอียด ความต้องการ และประเมินราคาเบื้องต้นได้

สามารถติดต่อทีมงานได้จากช่องทางไหน?

สามารถติดต่อทีมงาน AZRAEL ได้ผ่าน Discord อย่างเป็นทางการ เพื่อสอบถามข้อมูลสินค้า แจ้งปัญหาการใช้งาน หรือสอบถามเกี่ยวกับบริการต่าง ๆ
